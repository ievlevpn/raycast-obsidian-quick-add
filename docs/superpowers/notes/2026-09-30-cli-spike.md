# Obsidian CLI / QuickAdd interactive spike — 2026-09-30

Obsidian app 1.13.7 (installer 1.12.7), QuickAdd 2.27.0, vault main-vault.

## CLI availability
- Binary: `/Applications/Obsidian.app/Contents/MacOS/obsidian-cli` (not on PATH by default).
- Talks to the running app over `~/.obsidian-cli.sock`.
- Setting stored in `~/Library/Application Support/obsidian/obsidian.json` as top-level `"cli": true`.
  Toggling it needed an Obsidian restart before the CLI accepted commands.
- **Exit code is 0 even on failure.** Messages seen on stdout:
  - `Command line interface is not enabled. Please turn it on in Settings > General > Advanced.`
  - `Error: Command "quickadd:nosuch" not found. It may require a plugin to be enabled.`
  - `Vault not found.` (unknown `vault=` name)
  - `The CLI is unable to find Obsidian. Please make sure Obsidian is running and try again.` (from binary strings; not observed)
- `vault=<name>` selects the vault. A registered-but-closed vault gets **opened in a new window** as a side effect.
  `vault=srs-test-vault` (no QuickAdd) still returned main-vault's choices — the command ran in the other window.

## quickadd:* commands
- `quickadd:list` → `{"ok":true,"count":N,"choices":[{id,name,type,command,path,runnable}]}` (~35 ms).
- `quickadd:check choice=<name>` → `{ok, missing:[{id,label,type,optional,optionCount,placeholder}], missingFlags}`.
  Project note's tag picker appears as `{id:"__qa.captureTargetFilePath.<choiceId>", type:"dropdown", optionCount:4}`.
- `quickadd:interactive choice=<name>|id=<id> [vars=<json>]` → `{ok, choice, host:"127.0.0.1", port, sessionId, token, capabilities:["abort","outcome-effect"]}`.

## Interactive protocol (HTTP on 127.0.0.1:<port>, `?session=<id>&token=<token>` on every call)
- `GET /poll` → one event: `{kind:"prompt", requestId, prompt}` | `{kind:"idle"}` (after 25 s wait) | `{kind:"done", result}` | `{kind:"error", error}`.
- `POST /reply` JSON `{requestId, value, cancelled?}` → `{ok:true}`.
- `POST /abort` → `{ok:true, interrupted:N}`; next poll → `{kind:"error", error:"Execution cancelled by user"}`.
- Server timeouts: poll watchdog 75 s (no poll for 75 s → session ends "Interactive client disconnected."),
  idle poll 25 s, attach timeout 30 s, cleanup 60 s, max 32 sessions.
  → the client must keep polling while the user is answering.
- Prompt types (from source): `form {fields:[{id,label,type,placeholder,defaultValue,description,options,displayOptions,dateFormat,optional,...}]}`,
  `input {header,placeholder,defaultValue,multiline}`, `suggester {placeholder,allowCustomInput,items:[{title,value}]}`,
  `multiselect {placeholder,allowCustomInput,items,preselected}`, `checkbox {header,items:[{title,value,checked}]}`,
  `date {header,placeholder,defaultValue,dateFormat,withTime}`, `confirm {header,text}` (boolean reply), `info {header,text[]}`.
  Form field types seen: `text`, `dropdown` (with `options` + `displayOptions`). Source also maps `file-picker`→`suggester`; others: textarea, number, slider, date, field-suggest, checkbox.
